Batch Image Editor That Doesn't Upload Your Files

Editing thirty photos one by one is the slowest way to resize a folder. TinyPS is a batch image editor that applies the same edit to every file on your device — no upload, no per-image credit, no waiting.

A batch image editor opens many images at once and applies the same operation to all of them. TinyPS does it locally: add a folder, set the crop, size or quality once, and export every page as a single ZIP. Nothing is uploaded, so batch jobs on private photos stay private.

Batch editing, locally

TinyPS opens multiple images as separate pages. Apply per-page settings — resize, crop, compress, convert — then export them all as a single ZIP. All of it runs in your browser.

Common batch jobs you can do privately

  • Resize a whole folder to a fixed width for a website.
  • Compress screenshots before emailing them.
  • Convert PNGs to WebP to save space.
  • Add a watermark or text layer across many images.

How to batch edit without uploading

  1. Open TinyPS and load all the images you want.
  2. Set resize / crop / compression per page (or repeat the same setting).
  3. Review each page in the thumbnail strip.
  4. Click export and TinyPS bundles everything into one ZIP on your device.

Why local batch beats cloud batch

Cloud batch tools see every file you process. With TinyPS the folder never leaves your machine, which matters for client work, IDs and unreleased product shots.

Frequently asked questions

How do I edit many images at once?

Open the TinyPS editor and add a whole folder or a multi-select of images — it becomes a multi-page workspace. Apply crop, resize, filters or compression to the active page, then use “apply to all pages” to propagate it. Export the batch as one ZIP.

Can I compress or resize a whole folder of photos?

Yes, and it is the most common batch job. Set the target format, dimensions or quality once and TinyPS applies it to every page in the workspace. There is no limit on how many pages a batch can hold, apart from your device's memory.

Does batch editing upload my files?

No. Batch processing runs on your device exactly like single-image editing. There is no server round-trip, which is what makes large batches of confidential photos practical.

What is the best free batch image editor for Chrome?

For privacy and cost, a local extension is the practical answer: TinyPS batch-edits, compresses and converts without uploads, without a per-image credit and with no watermark. Most online batch tools require an upload and cap free usage.

Can I export a batch of edited images as a ZIP?

Yes — every page in the workspace can be exported together as a single ZIP, with the output format of your choice (JPEG, PNG, WebP, BMP or GIF).

How many images can I edit in one batch?

There is no fixed cap in the editor; the practical limit is your device's free memory, since all pages are held locally for instant preview. For very large folders, work in chunks.
