# TinyPS — Privacy-First Local Image Editor (Chrome Extension)

TinyPS is a fully local-running image editing extension built for privacy-conscious users: your photos **never leave your device**. All processing happens in the browser / on your machine — no uploads, no servers, no accounts.

- Website: https://www.tinyps.top/
- Chrome Web Store: https://chromewebstore.google.com/detail/knlnllmbmcjglhnphedilklcnmhbggen
- Microsoft Edge Add-ons: https://microsoftedge.microsoft.com/addons/search/TinyPS

---

## Key Features

- **100% local processing** — images never leave your device. No cloud, no uploads, no accounts.
- **Edit any web image in one click** — right-click any image on a web page → "Edit image with TinyPS" to open it in the local editor instantly.
- **AI background removal** — a lightweight on-device model removes backgrounds locally (no network needed).
- **Batch editing** — batch crop, resize, apply filters, and convert formats.
- **Local compression** — shrink image file size dramatically, all on your machine.
- **Full toolkit** — crop, rotate, filters, adjustments, watermark, and format conversion (JPG / PNG / WEBP, etc.).

## Installation

1. **Chrome Web Store / Edge Add-ons** (recommended): use the store links above for one-click install.
2. **Manual install (zip)**:
   - Download the extension package: https://www.tinyps.top/downloads/tinyps-extension.zip
   - Unzip to get the `tinyps-extension` folder.
   - Open your browser's Extensions page → enable "Developer mode" → "Load unpacked" → select that folder.
   - Step-by-step illustrated guide: https://www.tinyps.top/install.html

## How to Use

- **Web images**: right-click any image on a web page and choose "Edit image with TinyPS".
- **Local files**: open the extension and pick a local image to start editing.
- **Online editor**: use the Online Editor on the website — it also runs entirely locally in your browser.

## Privacy Promise

All image computation runs on your device. We **do not collect, upload, or store** any of your images or edits. No accounts, no telemetry, no third-party data selling.
