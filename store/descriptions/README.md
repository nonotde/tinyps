# TinyPS — Chrome Web Store 详情（长描述）

本目录存放 Chrome 网上应用店「详情」（详细描寫 / long description）的多语言版本，用于粘贴进开发者后台各语种的「详情」框（上限 16000 字符）。

## 文件对照（与扩展 `_locales` 语种一致）

| 文件 | 语言 |
|------|------|
| `en.txt` | English |
| `zh_CN.txt` | 简体中文 |
| `zh_TW.txt` | 繁體中文 |
| `de.txt` | Deutsch |
| `fr.txt` | Français |
| `ja.txt` | 日本語 |
| `ko.txt` | 한국어 |
| `ru.txt` | Русский |
| `ar.txt` | العربية (RTL) |
| `fa.txt` | فارسی (RTL) |

## 用法
1. 打开 Chrome 开发者后台 → 对应扩展 → 「商店详情」。
2. 在左侧语言列表选择一种语言，把对应 `.txt` 全文粘贴进「详情」框。
3. 阿拉伯语、波斯语为 RTL，后台会自动按语言方向显示，直接粘贴纯文本即可。

## 内容包含
- 隐私承诺（本地处理、不上传）
- 核心功能（一键编辑网页图、AI 抠图、批量、压缩、工具箱）
- **新增功能**（已写入）：自由裁剪保留内/外、自由旋转 Pro、水印文字透明度+旋转继承、AVIF 导出
- 使用方式、支持格式

> 注：manifest 内 132 字符的短描述（`__MSG_extDesc__`）与此处的「详情」是两套字段，互不影响。
