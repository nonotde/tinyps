TinyPS — бесплатное и лёгкое расширение для браузера, упрощённый Photoshop, работающий полностью офлайн. Кадрирование, масштабирование, поворот, сжатие, преобразование форматов, водяные знаки, монтаж GIF и удаление фона с ИИ — всё выполняется локально на 100 %. Ваши фотографии никогда не покидают устройство. Никаких серверов, аккаунтов и слежки.

Зачем нужен офлайн-редактор?
Большинство «онлайн-редакторов» загружают ваши изображения на свои серверы, где те обрабатываются, индексируются и хранятся — порой для обучения ИИ. TinyPS работает наоборот: альтернатива Photoshop целиком на вашем компьютере. Локальная обработка — это защита: TinyPS не передаёт данные третьим лицам и соблюдает принцип «минимальной необходимости».

Творчество с настоящими слоями
TinyPS — полноценный многослойный редактор:
- Вставляйте любое изображение новым слоем, добавляйте текстовые слои, меняйте порядок, блокируйте, скрывайте и объединяйте
- Трансформируйте каждый слой: масштаб, перемещение, поворот 90/180/270°, отражение, сброс — с историей отмены на 10 шагов
- Предустановки кадрирования (1:1, 4:3, 16:9, 3:2, 9:16) бесплатны; свободное кадрирование (Pro) добавляет «Сохранить внутри / снаружи»: оставить только выделенную область или удалить содержимое рамки. Полосы сшиваются, вырезанные места становятся прозрачными
- Свободный поворот (Pro): перетащите значок в центре, чтобы вращать на любой угол; при приближении к 90° срабатывает магнитная привязка
- Точная подстройка (Pro): ◀/▶ ровно на 1° или ввод угла 0–359°; выбранный слой вращается вокруг своего центра без изменения пикселей
- Прозрачность текста водяного знака регулируется (по умолчанию 100 %); новый текст наследует угол предыдущего
- Анимированные GIF покадрово: GIF делится на страницы по кадрам с сохранением задержек; экспорт «Анимированный GIF» рядом с «Пакетный ZIP»
- Работайте с миниатюрами всех слоёв и точно перемещайте элементы мышью или клавиатурой
Слои позволяют создавать композиции: визитки, графику для соцсетей, коллажи товаров или аккуратно вырезанный объект на новом фоне. Наложите логотип отдельным слоем и меняйте его, не повреждая оригинал.

Сжатие и преобразование без потери качества
- Прямое копирование: неизменённые файлы копируются байт в байт
- Точно задавайте целевой размер, удаляйте метаданные (EXIF), регулируйте качество одним ползунком
- Преобразуйте между распространёнными форматами, включая экспорт AVIF
- Пакетно экспортируйте все страницы в один ZIP без внешних инструментов
- Экспорт AVIF использует локальный WASM-кодек, загружаемый при первом применении, без влияния на запуск
Фото товара сжимается с 5 МБ до 300 КБ без видимой разницы — страница грузится быстрее. Точный целевой размер задаёт компромисс между объёмом и чёткостью; AVIF делает файлы ещё меньше.

Удаление фона на вашем устройстве
TinyPS Pro предлагает удаление фона с ИИ (u2netp и ONNX Runtime WebAssembly). Модель работает на CPU в браузере: без облака, API и загрузки. За секунды получайте прозрачные PNG и WebP, даже офлайн.
Ещё сомневаетесь? Бесплатные пользователи запускают настоящее удаление и видят результат: объект резкий в круглом окне, остальное размыто и затемнено — со значком «Pro preview», кнопками «Обновить для сохранения» и «Пробный период 3 дня», который сразу применяет вырезание. Холст остаётся неизменным.

Частые вопросы
TinyPS загружает мои изображения? Нет. Редактирование не делает сетевых запросов. Данные уходят только при загрузке изображения по URL или активации Pro (ключ лицензии и ID устройства через прокси). Изображения никогда не передаются и не анализируются.
Работает офлайн? Да. После установки кадрирование, сжатие, преобразование, удаление фона и монтаж GIF работают без сети.
Заменяет Photoshop для быстрых задач? Для кадрирования, масштабирования, сжатия, преобразования, текста и вырезания — да. Но без кистей, масок и CMYK.
WebP и AVIF? WebP читается и записывается; экспорт AVIF через локальный WASM-кодек. AVIF пока нельзя открыть как исходное изображение.
Замедлит ли экспорт AVIF? Нет. Кодек загружается только при первом использовании, без влияния на запуск и без сети.
Монтаж анимированных GIF? Да. GIF делится на страницы по кадрам с задержками, до 60 кадров, экспорт обратно в GIF — рендер и кодирование локальные.
Что такое пакетная обработка? Функция Pro: записывает изменения текстовых и заливочных слоёв (текст, цвет, размер, прозрачность, позиция, заливка, поворот) и повторяет их одним щелчком на всех страницах.
Можно попробовать Pro до оплаты? Да, каждая функция Pro имеет 3 дня без карты, офлайн до 24 часов.
Можно бесплатно попробовать удаление фона? Да. Бесплатные пользователи видят настоящее удаление в предпросмотре: объект резкий в круглом окне, остальное размыто. Обновите, начните пробный период или закройте без изменений.
«Сохранить внутри / снаружи»? «Внутри» оставляет только выделенную область; «снаружи» удаляет содержимое рамки и сохраняет вокруг. Полосы сшиваются, отверстия становятся прозрачными.
Свободный поворот на любой угол? Да. В Pro перетащите значок в центре; у 90° срабатывает магнитная привязка. Без конфликта с бесплатными 90/180/270°.
Что даёт точная подстройка? Наклоняйте на 1° или вводите 0–359°. Слой вращается вокруг центра без изменения пикселей, отмена работает чисто.
Прозрачность водяного знака регулируется? Да, по умолчанию 100 %, уменьшайте как нужно; новый текст наследует угол предыдущего.
Почему ползунок качества иногда серый? Нормально: качество только для форматов с потерями (JPEG, WebP, AVIF); PNG, BMP и GIF без потерь.
Сохраняются ли настройки? Да. Цвет, прозрачность, мозаика, текст, размер и угол сохраняются между страницами и сессиями; новое изображение использует последний размер холста. Обновление сбрасывает интерфейс, но сохраняет лицензию.
Пакетный режим? Да. Откройте несколько изображений, настройте каждую страницу и экспортируйте в один ZIP.
Pro — это подписка? Пожизненная лицензия или месячный/годовой план; одна лицензия на три устройства.
Безопасна ли лицензия? Активация отправляет только ключ и анонимный ID устройства через прокси. Данные изображений не передаются.
Mac/Windows/Linux? Да, на всех распространённых системах в Microsoft Edge и других браузерах на базе Chromium.
Китайский интерфейс? Да, упрощённый и традиционный китайский среди 10 встроенных языков.
Хватает ли бесплатной версии? Для большинства повседневных задач — сжатие, преобразование, кадрирование, текст, коллажи, GIF — да. Pro только для удаления фона с ИИ с сохранением, свободного кадрирования, свободного поворота, точной подстройки, заливочных слоёв и пакетной обработки.
Будет ли тормозить? Обработка локальная, скорость зависит от компьютера; сжатие и преобразование мгновенные, удаление фона — за секунды.
