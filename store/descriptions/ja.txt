TinyPS — プライバシー重視のローカル画像編集ツール（Chrome 拡張機能）

TinyPS はプライバシーを重視する方のために作られた、完全にローカルで動作する画像編集の拡張機能です。写真がデバイスから外に出ることはありません。すべての処理はブラウザーやお使いのパソコン内で完結します。アップロードなし、サーバーなし、アカウントなし、通信収集なし。

主な機能
• Web 上の画像をワンクリックで編集——Web ページの任意の画像を右クリックし「TinyPS で画像を編集」を選ぶと、ローカルエディターですぐに開きます。
• AI 背景除去——軽量なオンデバイスモデルがローカルで背景を除去します。ネットワーク不要。
• 一括編集——一括で切り抜き、リサイズ、フィルター適用、フォーマット変換。
• ローカル圧縮——ファイルサイズを大幅に削減。すべてパソコン内で完了し、通信しません。
• 充実のツール——切り抜き、回転、フィルター、調整、ウォーターマーク、フォーマット変換（JPG / PNG / WEBP / BMP / GIF など）。

新機能
1. フリークロップの「内側を残す / 外側を残す」——外側を残すと枠内の領域を削除します。横幅いっぱいや高さいっぱいの帯は自動でつなぎ合わせられ、局部に穴を空けて透明に抜くこともできるので、形状の切り出しや特定領域の消去が簡単です。
2. 自由回転（Pro）——中央のアイコンをドラッグすると、画像の中心を軸に任意の角度で回転。90° で磁着するので、素早く正確に正しい向きに直せます。
3. ウォーターマーク文字の不透明度——文字の透明度を設定できます（初期値 100%）。新しい文字は直前の文字の回転状態を引き継ぐため、複数行の斜めウォーターマークの配置がずっと速くなります。
4. AVIF 書き出し——新しい出力フォーマット。ローカルの WASM でエンコードします。遅延読み込み（lazy load）のため、アプリの起動を遅くすることはありません。

使い方
• Web 画像：ページ上の画像を右クリック →「TinyPS で画像を編集」。
• ローカルファイル：拡張機能を開き、ローカルの画像を選択。
• オンラインエディター：サイトの Online Editor もブラウザー内で完全にローカル動作します。

プライバシーに関する約束
すべての計算はお使いのデバイス上で行われます。当社がお客様の画像や編集内容を収集、アップロード、保存することは一切ありません。アカウントなし、通信収集なし、第三者へのデータ販売なし。

対応フォーマット：読み込み JPG / PNG / WEBP / BMP / GIF；書き出し JPG / PNG / WEBP / BMP / GIF / AVIF。
