TinyPS — 隐私优先的本地图片编辑器（Chrome 扩展）

TinyPS 是一款完全在本地运行的图片编辑扩展，专为重视隐私的用户打造。你的照片永远不会离开你的设备：所有处理都在浏览器、本机内完成。无上传、无服务器、无账号、无遥测。

核心功能
• 一键编辑网页图片——在网页任意图片上右键，选择「用 TinyPS 编辑图片」，即可在本地编辑器瞬间打开。
• AI 智能抠图——内置轻量模型，于本地完成人像/物体抠图，无需联网。
• 批量编辑——批量裁剪、缩放、加滤镜、转换格式。
• 本地压缩——大幅减小文件体积，全程在本机完成，不联网、不上传。
• 功能齐全——裁剪、旋转、滤镜、调整、水印、格式转换（JPG / PNG / WEBP / BMP / GIF 等）。

新增功能
1. 自由裁剪「保留内 / 保留外」——保留外会删除框内区域。整幅横带或竖带自动拼接，局部区域可挖洞透出透明，方便抠出形状或清除特定区域。
2. 自由旋转（Pro）——拖动画面中心的图标，可绕图片中心任意角度旋转，并带 90° 磁吸，方便快速精准转正。
3. 水印文字透明度——可设置文字透明度（默认 100%）。新增文字会继承上一段文字的旋转状态，多行倾斜水印排布更快。
4. AVIF 导出——新增输出格式，由本地 WASM 编码。采用懒加载，不会拖慢应用启动速度。

使用方式
• 网页图片：在页面任意图片上右键 →「用 TinyPS 编辑图片」。
• 本地文件：打开扩展，选择本地图片开始编辑。
• 在线编辑器：官网的 Online Editor 同样完全在浏览器本地运行。

隐私承诺
所有运算均在你的设备本地完成。我们不收集、不上传、不存储你的任何图片与编辑内容。无账号体系、无遥测、无第三方数据买卖。

支持格式：导入 JPG / PNG / WEBP / BMP / GIF；导出 JPG / PNG / WEBP / BMP / GIF / AVIF。
