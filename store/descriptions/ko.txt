TinyPS — 개인정보 우선 로컬 이미지 편집기(Chrome 확장 프로그램)

TinyPS는 개인정보를 중시하는 사용자를 위해 만들어진, 완전히 로컬에서 실행되는 이미지 편집 확장 프로그램입니다. 사진이 절대 기기를 떠나지 않습니다. 모든 처리가 브라우저, 내 컴퓨터 안에서 끝납니다. 업로드 없음, 서버 없음, 계정 없음, 텔레메트리 없음.

주요 기능
• 웹 이미지를 원클릭으로 편집——웹 페이지의 아무 이미지나 마우스 오른쪽 버튼으로 클릭하고 "TinyPS로 이미지 편집"을 선택하면 로컬 편집기에서 즉시 열립니다.
• AI 배경 제거——가벼운 온디바이스 모델이 네트워크 없이 로컬에서 배경을 제거합니다.
• 일괄 편집——일괄로 자르기, 크기 조정, 필터 적용, 형식 변환.
• 로컬 압축——파일 크기를 크게 줄입니다. 모두 내 컴퓨터에서 처리되어 전송되지 않습니다.
• 풀 툴킷——자르기, 회전, 필터, 조정, 워터마크, 형식 변환(JPG / PNG / WEBP / BMP / GIF 등).

새로운 기능
1. 자유 자르기 "안쪽 유지 / 바깥쪽 유지"——바깥쪽 유지는 상자 안쪽 영역을 삭제합니다. 가로 또는 세로 전체 띠는 자동으로 이어 붙이고, 국소적으로 구멍을 뚫어 투명하게 만들 수 있어 형태를 오려내거나 특정 영역을 지우기 쉽습니다.
2. 자유 회전(Pro)——가운데 아이콘을 드래그하면 이미지 중심을 축으로 어떤 각도로든 회전합니다. 90° 자석 맞춤이 있어 빠르고 정확하게 바로잡을 수 있습니다.
3. 워터마크 글자 투명도——글자의 투명도를 설정할 수 있습니다(기본값 100%). 새 글자는 바로 앞 글자의 회전 상태를 물려받아, 여러 줄 비스듬한 워터마크 배치가 훨씬 빨라집니다.
4. AVIF 내보내기——새로운 출력 형식. 로컬 WASM으로 인코딩합니다. 지연 로드(lazy load) 방식이라 앱 시작을 늦추지 않습니다.

사용 방법
• 웹 이미지: 페이지의 이미지를 오른쪽 클릭 → "TinyPS로 이미지 편집".
• 로컬 파일: 확장 프로그램을 열고 로컬 이미지를 선택.
• 온라인 편집기: 사이트의 Online Editor도 브라우저에서 완전히 로컬로 실행됩니다.

개인정보 약속
모든 계산은 사용자의 기기에서 이루어집니다. 당사는 귀하의 이미지나 편집 내용을 수집·업로드·저장하지 않습니다. 계정 없음, 텔레메트리 없음, 제3자 데이터 판매 없음.

지원 형식: 가져오기 JPG / PNG / WEBP / BMP / GIF; 내보내기 JPG / PNG / WEBP / BMP / GIF / AVIF.
