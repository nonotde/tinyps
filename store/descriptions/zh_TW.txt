TinyPS — 隱私優先的本地圖片編輯器（Chrome 擴充功能）

TinyPS 是一款完全在本地執行的圖片編輯擴充功能，專為重視隱私的使用者打造。你的照片永遠不會離開你的裝置：所有處理都在瀏覽器、本機內完成。無上傳、無伺服器、無帳號、無遙測。

核心功能
• 一鍵編輯網頁圖片——在網頁任意圖片上右鍵，選擇「用 TinyPS 編輯圖片」，即可在本地編輯器瞬間開啟。
• AI 智慧去背——內建輕量模型，於本地完成人像/物件去背，無需聯網。
• 批次編輯——批次裁切、縮放、加濾鏡、轉換格式。
• 本地壓縮——大幅縮減檔案體積，全程在本機完成，不聯網、不上傳。
• 功能齊全——裁切、旋轉、濾鏡、調整、浮水印、格式轉換（JPG / PNG / WEBP / BMP / GIF 等）。

新增功能
1. 自由裁切「保留內 / 保留外」——保留外會刪除框內區域。整幅橫帶或直帶自動拼接，局部區域可挖洞透出透明，方便摳出形狀或清除特定區域。
2. 自由旋轉（Pro）——拖動畫面中心的圖示，可繞圖片中心任意角度旋轉，並帶 90° 磁吸，方便快速精準轉正。
3. 浮水印文字透明度——可設定文字透明度（預設 100%）。新增文字會繼承上一段文字的旋轉狀態，多行傾斜浮水印排布更快速。
4. AVIF 匯出——新增輸出格式，由本地 WASM 編碼。採用懶載入，不會拖慢應用程式啟動速度。

使用方式
• 網頁圖片：在頁面任意圖片上右鍵 →「用 TinyPS 編輯圖片」。
• 本地檔案：開啟擴充功能，選擇本地圖片開始編輯。
• 線上編輯器：官網的 Online Editor 同樣完全在瀏覽器本地執行。

隱私承諾
所有運算均在你的裝置本地完成。我們不收集、不上傳、不儲存你的任何圖片與編輯內容。無帳號體系、無遙測、無第三方資料買賣。

支援格式：匯入 JPG / PNG / WEBP / BMP / GIF；匯出 JPG / PNG / WEBP / BMP / GIF / AVIF。
