免费的 Chrome 图片编辑扩展——本地、无水印

TinyPS 是一款在设备上做真正编辑的免费 Chrome 图片编辑扩展——导出无水印、不强制账号、不计费。Pro 仅在你需要时增加少量高级工具。

免费扩展能做什么

  • 裁剪、旋转、按比例缩放。
  • 图层、文字、滤镜与画布工具。
  • 压缩并转换 JPEG/PNG/WebP/BMP/GIF。
  • 多页批量与 ZIP 导出。
  • 任何导出都无水印。

几秒装好

  1. 打开 TinyPS 的 Chrome 网上应用店页面。
  2. 点击「添加至 Chrome」。
  3. 在任意网页图片上右键选「用 TinyPS 编辑图片」，或打开扩展。
  4. 开始编辑——无需注册。

免费与 Pro，直说

免费覆盖日常编辑与导出。Pro（终身买断 $24.9，支持支付宝；或月付 $1.99、年付 $9.9）额外提供自由裁剪、填充图层与 AI 去背景。

本地扩展为什么优于标签页工具

本地扩展可离线工作、带右键菜单、绝不上传图片。仅标签页的工具常上传文件，且免费导出带水印。
