离线图片编辑器：不联网也能修图

如果你的工作涉及敏感图片，一个会联网回传的网页工具就是隐患。TinyPS 是一款完全在浏览器里运行的离线图片编辑器——无服务器、无同步、无泄露。

这里说的「离线图片编辑器」是什么

TinyPS 以 Chrome/Edge 扩展形式加载，也有免费的浏览器内编辑器。打开后，裁剪、旋转、缩放、图层、文字、滤镜、压缩、转换每一步都在你的设备上完成。拔掉网线也能继续编辑。

为什么要在离线状态修图

  • 隐私：任何文件都不会发往服务器。
  • 可靠：没有服务器宕机、没有限流、不用排队。
  • 速度：普通图片本地处理即时完成。
  • 成本：核心编辑免费，没有按张计费。

如何开始离线编辑

  1. 从 Chrome 网上应用店或 Edge 外接程序安装 TinyPS（或打开在线编辑器）。
  2. 打开一张图片——从磁盘，或在任意网页图片上右键选「用 TinyPS 编辑图片」。
  3. 用图层、裁剪、缩放、压缩或转换进行编辑。
  4. 导出为 JPEG/PNG/WebP/BMP/GIF，或多页打包成 ZIP。

离线 vs「免费在线编辑器但仍上传」

很多「免费编辑器」在标签页里运行却会把文件上传处理。TinyPS 即使在在线编辑器模式下也本地处理，离线保证始终成立。

常见问题

TinyPS 真的可以完全不联网吗？

可以。编辑、压缩、转换都不需要网络，唯一的网络请求是你激活付费功能时的 Pro 许可证校验。

离线编辑必须安装东西吗？

装扩展体验最好，也可以用免费的在线编辑器，它同样在你的浏览器里本地运行。

离线编辑器支持哪些格式？

JPEG、PNG、WebP、BMP、GIF——包含 Chrome 原生无法导出的格式（自研编码器）。
