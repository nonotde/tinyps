本地去背景，照片一个像素都不上传

大多数去背景工具会把你的照片上传到云端，在别人的服务器上处理再传回来。TinyPS 反过来：AI 模型在你的浏览器里运行，照片永远不会离开你的电脑。

如何离线去除背景

大约 20 秒，零上传：
  1. 给 Chrome 或 Edge 安装 TinyPS 扩展（或打开免费的在线编辑器，免安装）。
  2. 在 TinyPS 里打开你的图片。
  3. 点击「去除背景」。u2netp 模型通过 WebAssembly 在本地运行。
  4. 导出带透明背景的 PNG，或拖到别的图层继续编辑。

「不上传」为什么重要

工具一旦上传你的照片，就可能存储它、用它训练，并成为数据泄露的目标。TinyPS 让文件始终留在你的设备上：
  • 无云账号、无 API Key、无需排队。
  • 机密截图、证件照、产品图绝不会碰到服务器。
  • EXIF 定位和元数据不会泄露给第三方。
  • 飞机上、地下室、任何地方都能离线用。

常见问题

TinyPS 去背景时会把我的图片上传吗？

不会。u2netp 分割模型通过 ONNX Runtime WebAssembly 完全在你的设备上运行，没有任何云端 API 调用，照片永远不会离开你的电脑。

免费版包含去背景吗？

去背景属于 Pro 功能。免费版涵盖所有基础编辑、压缩、格式转换与批量 ZIP 导出。

去背景后能导出哪些格式？

可导出 PNG（带透明）、JPEG、WebP、BMP、GIF，以及把多页一次性打包成 ZIP。
