常见问题

TinyPS 免费吗？免费版和 Pro 有什么区别？

核心编辑器永久免费：裁剪、缩放、旋转、图层、文字、滤镜、格式转换与批量 ZIP 导出。Pro（终身买断 $24.9，或月付 $1.99、年付 $9.9）额外提供自由裁剪、填充图层（纯色 / 马赛克 / 吸管）以及本地 AI 去除背景。

TinyPS 会把我的照片上传到服务器吗？

不会。所有编辑、压缩与转换都在你的浏览器本地完成。唯一的网络请求，是激活 Pro 时把许可证密钥与一个随机设备 ID 发给支付方 Creem——绝不会发送你的图片。

TinyPS 能完全离线使用吗？

可以。编辑、压缩、转换都不需要联网。AI 去背景模型（u2netp）随扩展一起分发，通过 WebAssembly 在你的设备上运行。

AI 去背景是怎么工作的？我的照片会被传出去吗？

它通过 ONNX Runtime WebAssembly，在你本机运行 u2netp 分割模型。照片永远不会离开你的电脑，没有任何云端 API 调用。

TinyPS 支持哪些图片格式？

可读取并导出 JPEG、PNG、WebP、BMP、GIF——包含 Chrome 原生无法导出的格式（自研编码器）。多页还可一次性导出为一个 ZIP。

去背景功能在免费版里吗？

去背景属于 Pro 功能。免费版涵盖所有基础编辑、压缩、格式转换与批量导出。

TinyPS 和 Photopea、remove.bg、Squoosh 有什么区别？

那些工具都在服务器上处理你的图片（或仍在会上传的标签页里处理）。TinyPS 的一切都在你自己的设备上完成，绝不上传文件，这是它最核心的隐私优势。它还内置了 u2netp，去背景无需账号、无需 API Key。详见隐私政策。

在国内能用支付宝购买 Pro 吗？

可以。终身买断档（$24.9 一次性）支持支付宝；月付 / 年付订阅支持信用卡与 PayPal。收款由 Creem 处理，符合国内支付习惯。
