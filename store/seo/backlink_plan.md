# TinyPS 外链（Backlink）SEO 方案

> 依据微信公众号文章《110 个外链资源，我把每个网站都列出来了》（2026-11-08）整理。
> 文章本身是「资源清单」，本方案只摘取**对 TinyPS 有用**的部分，并转化为可执行的提交计划。

---

## 一、这篇文章对 SEO 有帮助吗？

**有帮助，而且是当前优先级最高的事之一。**

| 我们已做的 SEO | 类型 | 状态 |
|---|---|---|
| Bing 验证 meta | 技术/收录 | ✅ |
| IndexNow 推送 13 URL | 技术/收录 | ✅ |
| 长尾内容页 6 主题 ×2 站 | 站内内容 | ✅ |
| sitemap 13 URL | 技术/收录 | ✅ |
| 百度 + GoatCounter 统计 | 数据 | ✅ |
| **外链（backlink）** | **站外/排名** | **❌ 缺失** |

外链是 Google / 百度排名三大核心因素（内容、技术、外链）里我们唯一还没动手的。
TinyPS 英文站托管在 GitHub Pages（域名权重低，尤其需要外链），中文站 `pic.zxxdb.com` 也需更多权威引用。
这篇文章给的 104 个站点，正好是一批**免费、低成本**的提交入口。

**但文章也明确提醒**：判断标准是「相关性，不是数量」；110 条里真正适合新站第一批的约三分之一。
所以本方案只筛相关性高的站点，不盲目堆量。

## 二、执行顺序（改编自文章第 07 节，适配 TinyPS）

1. **先提交 10 个相关目录站**（无需审核/自动化优先），确认产品页能接住流量
2. **写 1 篇真有用的教程**，发到 dev.to / Hashnode（英文），同步到中文社区（少数派、linux.do）—— 教程草稿已备好：`tutorial_draft_en.md`
3. **产品演示版就绪后**，挑 2 个发布平台错开发布（Product Hunt、Uneed）
4. **之后每月**从清单挑 3–5 个新站持续补充
5. **每季度**回看统计（GoatCounter / 百度），看哪些外链带来真实访问
